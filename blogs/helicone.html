Helicone Connector: LLM Observability & Prompt Management for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #6019

1. The Vision: Prompt Lineage & Observability in Memory Graphs

Engineering teams routing production LLM traffic through Helicone store versioned prompt templates, curated evaluation datasets, automated LLM judges, and user ratings. When autonomous AI agents collaborate on application development, they must understand which prompt version is deployed in production, what benchmark test cases failed hallucination evaluators, and what feedback users submitted.

2. Architecture & Bounded Ingestion

The cognee-community-connector-helicone communicates with Helicone's REST API (supporting US, EU, and self-hosted instances) using API Key Bearer authentication.

Architectural Highlights:
  • Prompt Lineage & Versions: Ingests prompt templates, version tags, model configurations, and creation timestamps.
  • Curated Evaluation Datasets: Ingests benchmark suites, test inputs, and ground truth expectations.
  • Automated Evaluator Logic: Maps LLM-as-a-judge quality criteria and scoring modes into semantic memory.
  • Curated Feedback Traces: Bounded specifically to human-rated feedback (thumbs up/down, user comments) rather than raw proxy log dumping to protect graph health.

3. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_helicone import HeliconeConnector
import cognee

async def main():
    connector = HeliconeConnector(
        api_key="your_helicone_api_key",
        base_url="https://api.helicone.ai",
        fetch_prompts_flag=True,
        fetch_datasets_flag=True,
        fetch_evaluators_flag=True,
        fetch_feedback_traces_flag=True,
    )

    print("Fetching prompts, datasets, and traces from Helicone...")
    data = await connector.fetch_all()
    print(f"Retrieved {len(data['prompts'])} prompts and {len(data['datasets'])} datasets.")

    # Ingest into Cognee Knowledge Graph
    for p in data["prompts"]:
        await cognee.add(p["clean_text"])
    
    for d in data["datasets"]:
        await cognee.add(d["clean_text"])

    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())

4. Verification & Testing

The package contains an offline unit test suite validating prompt versions parsing, evaluation dataset extraction, feedback traces filtering, and 401 unauthorized error handling with zero live Helicone cloud dependencies.
