OpenStreetMap Places Connector: Zero-Key Geospatial Memory

By Bhomvrat Rai (@bhomvratrai-glitch) • Pull Request #503 • Issue #6187

1. The Problem: Local Places & Physical Context for AI Agents

AI assistants frequently need to answer questions about local physical environments: finding wheelchair-accessible libraries, cafes with evening opening hours, or parks within a walking district. Without an open geospatial bridge, developers were forced to rely on expensive commercial map APIs with strict paywalls.

2. Architecture: Leveraging the Overpass API

We built packages/connector/openstreetmap/ on top of the public OpenStreetMap Overpass API, enabling zero-key querying of nodes and ways:

Highlights:
• Zero API Keys Required: Works completely out-of-the-box with public Overpass API servers.
• Rich POI Attributes: Extracts opening hours, addresses, contact details, and wheelchair accessibility into structured Markdown.
• Attribution Compliance: Automatically attaches required OpenStreetMap contributor attribution (ODbL 1.0).
• Hermetic Testing: 5/5 unit tests passed offline in 0.61s.

3. Quickstart Code

import asyncio
import cognee
from cognee_community_connector_openstreetmap import openstreetmap_source

async def main():
    # Ingest cafes and libraries in central London
    source = openstreetmap_source(
        bbox=(51.500, -0.130, 51.515, -0.110),
        amenities=["cafe", "library", "park"],
        limit=25,
    )
    await cognee.add(source)
    await cognee.cognify()

    results = await cognee.search("Which cafes or libraries are wheelchair accessible?")
    for res in results:
        print("-", res)

if __name__ == "__main__":
    asyncio.run(main())
