AtCoder Submissions & Contest Trajectory Connector for Cognee

By Bhomvrat Rai • October 30, 2026 • topoteretes/cognee#6406

Architectural Overview

Competitive programmers solving contests on AtCoder (AtCoder Beginner Contest / ABC, AtCoder Regular Contest / ARC) lack an intuitive, contextual memory layer to query their historical weaknesses, difficulty plateaus, or recurring time-limit failures (TLEs). This connector bridges that gap by ingesting real-time submission data and official contest rating trajectories directly into Cognee Knowledge Graphs.

Key Capabilities

  • Historical Submission Extraction: Pulls problem IDs, languages (C++, Rust, Python), verdicts (AC, WA, TLE, MLE), execution times, and scores.
  • Contest Performance Trajectory: Records rank, performance ratings, and rating changes per round.
  • Deterministic Graph Node Hashing: Computes stable SHA-256 identifiers to prevent entity duplication across recurring ingest sweeps.

Usage Example

from cognee_community_connector_atcoder import AtCoderConnector

connector = AtCoderConnector(username="tourist")
documents = connector.fetch_documents(include_contests=True)

print(f"Ingested {len(documents)} competitive programming documents into Cognee.")
for doc in documents[:2]:
    print(doc["metadata"])
    print(doc["text"])
