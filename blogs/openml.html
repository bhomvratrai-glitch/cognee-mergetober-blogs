OpenML Benchmark Connector: Machine Learning Dataset Metadata for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5691

1. The Vision: Benchmark Discovery & Dataset Intelligence

Selecting reliable tabular machine learning benchmarks requires tracking dataset versions, classification/regression targets, reported data qualities (instances, dimensions, missing value ratios), academic citations, and licensing. OpenML publishes the world's most comprehensive ecosystem of open ML benchmarks. By connecting OpenML dataset metadata directly into Cognee Graph RAG memory, AI research copilots can query and reason about suitable benchmark datasets without downloading gigabytes of binary data files or executing expensive experiment runs.

2. Architecture & REST Discovery

The cognee-community-connector-openml package queries the official OpenML JSON REST API anonymously.

Key Architectural Capabilities:
  • Lightweight Metadata Harvesting: Retrieves dataset identification, version, description, tags, licensing, and academic citations via anonymous endpoints.
  • Statistical Qualities Ingestion: Normalizes statistical properties including NumberOfInstances, NumberOfFeatures, NumberOfClasses, and NumberOfMissingValues.
  • Target Attribute Resolution: Explicitly parses the declared supervised learning target column.
  • Lifecycle Status Tracking: Retains active and deactivated dataset visibility, ensuring researchers distinguish superseded datasets from deleted ones.
  • Zero Binary Overhead: Bounded specifically to discovery metadata; avoids downloading raw ARFF or Parquet files.

3. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_openml import OpenMLConnector
import cognee

async def main():
    # Configure numeric benchmark IDs (e.g. Iris: 61, German Credit: 31)
    connector = OpenMLConnector(
        dataset_ids=[61, 31],
        include_qualities=True
    )

    print("Fetching OpenML benchmark metadata...")
    datasets = await connector.fetch_all()
    print(f"Retrieved {len(datasets)} dataset cards.")

    # Ingest into Cognee Knowledge Graph
    for ds in datasets:
        await cognee.add(ds["clean_text"])
    
    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())

4. Verification & Testing

The connector includes a hermetic test suite validating dataset metadata extraction, statistical qualities parsing, missing/absent qualities handling, deactivated dataset tracking, and 404 API error isolation without requiring external network connectivity.
