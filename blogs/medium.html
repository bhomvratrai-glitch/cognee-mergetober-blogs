Engineering the Medium Article & Publication Connector

By Bhomvrat Rai (@bhomvratrai-glitch) • Pull Request #501 • Issue #5718

1. The Problem: Extracting Long-Form Technical Content

Medium is one of the world's most widely used platforms for technical tutorials, architectural designs, and engineering postmortems. For Cognee users building domain-specific knowledge bases, ingesting Medium essays without clutter (ads, sidebars, headers) was a major missing link.

2. Architecture & HTML-to-Markdown Transformation

Our implementation in packages/connector/medium/ incorporates a dedicated HTML parser using BeautifulSoup that strips clutter and renders rich Markdown:

Key Highlights:
• Feed & URL Ingestion: Ingest via author handle (@towardsdatascience) or explicit article URLs.
• Canonical Deduplication: Normalizes URLs by removing tracking parameters (utm_source) and hashes identifiers.
• 5/5 Unit Tests Passed: Tested parsing, feed generation, and dlt routing completely offline in 0.59s.

3. Quickstart Code

import asyncio
import cognee
from cognee_community_connector_medium import medium_source

async def main():
    # 1. Initialize Medium connector
    source = medium_source(
        authors=["@towardsdatascience"],
        article_urls=["https://medium.com/@author/building-ai-agents-with-memory"],
    )

    # 2. Ingest and extract knowledge graph
    await cognee.add(source)
    await cognee.cognify()

    # 3. Query ingested engineering knowledge
    results = await cognee.search("What are best practices for memory-enabled AI agents?")
    for res in results:
        print("-", res)

if __name__ == "__main__":
    asyncio.run(main())
