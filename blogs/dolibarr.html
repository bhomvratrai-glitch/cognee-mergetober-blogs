Dolibarr ERP/CRM Connector: Open-Source Enterprise Memory for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #6168

1. The Challenge: Unifying Open-Source ERP & CRM Intelligence

Dolibarr is one of the world's most widely deployed open-source ERP and CRM systems, powering operations, client accounts, quoting pipelines, and customer support for thousands of small and medium businesses. For autonomous AI agents, questions like "What is the status of Acme's support ticket, and did our updated proposal get signed?" require real-time correlation across disparate business entities.

2. REST Integration Architecture & Dolibarr Quirk Handling

The cognee-community-connector-dolibarr interfaces securely with Dolibarr's REST API module via the DOLAPIKEY authentication header, guaranteeing credentials never leak in query URLs.

Architectural Highlights:
  • Third-Parties & Accounts: Ingests client profiles, tax IDs, contact channels, and modification timestamps.
  • Contacts Directory: Maps employee roles, direct communication lines, and company associations.
  • Commercial Proposals: Pulls quote references, financial sums (excl/incl tax), and validation status.
  • Support Tickets: Ingests ticket tracking IDs, categories, severity levels, and message contents.
  • 404 Empty Record Resilience: Gracefully parses Dolibarr's idiosyncratic 404 "No records found" response as an empty list rather than an operational failure.
  • Privacy Safeguard: Restricted internal notes are shielded by default (include_private_notes=False).

3. Code Walkthrough: Ingestion into Cognee

import asyncio
from cognee_community_connector_dolibarr import DolibarrConnector
import cognee

async def main():
    connector = DolibarrConnector(
        base_url="https://erp.your-company.com",
        api_key="your_dolapikey_secret",
        include_private_notes=False
    )

    # Ingest accounts, contacts, quotes, and support tickets
    documents = await connector.to_documents(
        include_thirdparties=True,
        include_contacts=True,
        include_proposals=True,
        include_tickets=True,
        limit_per_type=20
    )

    # Cognify into vector and knowledge graph memory
    await cognee.add(documents)
    await cognee.cognify()

    await connector.close()

if __name__ == "__main__":
    asyncio.run(main())
