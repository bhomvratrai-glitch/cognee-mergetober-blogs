Ingesting LeetCode Submissions & Problem Solving Topology into Cognee

By Bhomvrat Rai • Issue #6179 • 5 min read

LeetCode is the global standard benchmark for algorithmic problem solving, software engineering interviews, and competitive programming. However, a software engineer's problem-solving history typically sits trapped in web profiles without semantic context. By integrating LeetCode problem statements, difficulty classifications (Easy, Medium, Hard), topic tags (Dynamic Programming, Graph Theory, Trees), and accepted submission histories into Cognee's AI Memory Engine, AI mentors and technical assistants gain full visibility into a developer's algorithmic capabilities.

Key Architectural Highlights

  • Public & Authenticated Ingestion: Ingests any public LeetCode user profile without login credentials via LeetCode's public GraphQL endpoint.
  • Algorithmic Taxonomy Graph: Automatically correlates problems with topic tags (Binary Search, DP, Bit Manipulation, Two Pointers) to construct a queryable skills graph.
  • Semantic Markdown Formatting: Synthesizes accepted submissions into clean Markdown documents with direct problem links, difficulty metadata, and timestamps.
  • Deterministic Entity Hashing: Uses SHA-256 ID hashing so re-syncs never create duplicate nodes in Cognee's graph.

Usage Example

from cognee_community_connector_leetcode import LeetCodeConnector

# Initialize connector for any public LeetCode username
connector = LeetCodeConnector(username="tourist", include_problem_details=True)

# Ingest recent accepted solutions
documents = connector.fetch_documents(limit=20)

for doc in documents:
    print(f"Problem: {doc['metadata']['title']} - {doc['metadata']['difficulty']}")
    print(f"Document ID: {doc['id'][:8]}...")
