Meilisearch Connector: Search Engine Document Memory for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5823

1. The Vision: Unifying Fast Search Indexes with Graph RAG

Meilisearch is renowned for sub-50ms typo-tolerant search across e-commerce product catalogs, knowledge base articles, and application records. However, keyword and faceted search indexes operate in silos from cognitive memory. By ingesting Meilisearch index documents directly into Cognee, autonomous agents can perform hybrid reasoning across lexical search records, entity graphs, and vector representations simultaneously.

2. Architecture & REST Discovery

The cognee-community-connector-meilisearch communicates with Meilisearch's REST API using API Key Bearer authentication.

Architectural Highlights:
  • Automated Index Discovery: Dynamically queries /indexes to discover and sync all accessible search indexes without requiring manual configuration.
  • Deterministic Document Pagination: Iterates through /indexes/{uid}/documents with bounded limits and configurable field allowlists.
  • Privacy & Attribute Protection: Filters sensitive columns (e.g. passwords, payment secrets) using strict field allowlists before embedding.
  • Clean Document Synthesis: Emits clean markdown records tagged with stable composite identities (meilisearch:{index_uid}:{doc_id}).

3. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_meilisearch import MeilisearchConnector
import cognee

async def main():
    connector = MeilisearchConnector(
        host="http://localhost:7700",
        api_key="your_meilisearch_master_key",
        indexes=["products", "articles"],
        limit_per_index=50,
    )

    print("Fetching documents from Meilisearch...")
    documents = await connector.fetch_all()
    print(f"Retrieved {len(documents)} searchable index documents.")

    # Ingest into Cognee Knowledge Graph
    for doc in documents:
        await cognee.add(doc["clean_text"])

    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())

The connector features a 100% hermetic unit test suite validating index discovery, paginated document retrieval, field filtering, and 401 unauthorized error handling with zero live Meilisearch instances required.
