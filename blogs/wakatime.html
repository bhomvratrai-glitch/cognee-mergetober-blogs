WakaTime Developer Activity Connector: Temporal Engineering Memory

By Bhomvrat Rai (@bhomvratrai-glitch) • Pull Request #502 • Issue #6218

1. The Problem: Connecting Time Telemetry to AI Context

Developers spend hundreds of hours coding across repositories, languages, and IDEs. WakaTime tracks this telemetry automatically, but until now, this operational data was trapped in isolated charts rather than accessible to an engineering AI agent.

2. Architecture & Metrics Transformation

Implemented in packages/connector/wakatime/, the connector pulls granular daily summaries and aggregate developer productivity overviews:

Key Capabilities:
• Multi-Dimensional Telemetry: Ingests durations per project, programming language, branch, and text editor.
• Cognitive Overview Documents: Generates multi-day productivity overviews with percentage distributions and daily averages.
• Hermetic Test Suite: Mocked REST client testing 100% of formatting, summaries, and dlt configurations.

3. Quickstart Code

import asyncio
import os
import cognee
from cognee_community_connector_wakatime import wakatime_source

async def main():
    source = wakatime_source(
        api_key=os.getenv("WAKATIME_API_KEY"),
        days_back=7,
        include_overview=True,
    )
    await cognee.add(source)
    await cognee.cognify()

    results = await cognee.search("Which project did I spend the most time coding on this week?")
    for res in results:
        print("-", res)

if __name__ == "__main__":
    asyncio.run(main())
