MotherDuck Serverless DuckDB Connector: System Telemetry & Warehouse Memory for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5880

1. The Vision: Analytical Telemetry & Warehouse Memory

A true organization AI brain isn't complete without internal system telemetry and analytical awareness. Cognee itself leverages DuckDB and MotherDuck for hybrid local-cloud analytics. By connecting MotherDuck database catalogs, shared repositories, and query execution histories directly into Cognee's Graph RAG memory, autonomous AI agents can answer questions about analytical workload bottlenecks, expensive queries, database sharing topologies, and real-time warehouse states.

2. Architecture & Telemetry Protection

The cognee-community-connector-motherduck package communicates with MotherDuck's REST API using Bearer Token authentication.

Architectural Highlights:
  • Database Catalog Mapping: Ingests database names, sizes in bytes, owner identities, sharing flags, and modification timestamps.
  • Data Sharing Catalogs: Tracks database shares, linked schemas, and access levels (e.g. read-only vs contributor).
  • Bounded Telemetry Ingestion: Query histories can be massive. The connector enforces configurable limit guards (default 50) and captures execution duration in milliseconds, status codes (SUCCESS, FAILED), and rows scanned to prevent memory bloating.
  • Clean Markdown Extraction: Formats SQL statements and database catalogs into structured semantic markdown ready for LLM vectorization.

3. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_motherduck import MotherDuckConnector
import cognee

async def main():
    connector = MotherDuckConnector(
        token="your_motherduck_token",
        fetch_queries=True,
        query_limit=25,
    )

    print("Fetching databases and telemetry from MotherDuck...")
    data = await connector.fetch_all()
    print(f"Retrieved {len(data['databases'])} databases and {len(data['queries'])} queries.")

    # Ingest into Cognee Knowledge Graph
    for db in data["databases"]:
        await cognee.add(db["clean_text"])
    
    for query in data["queries"]:
        await cognee.add(query["clean_text"])

    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())
