SurrealDB Multi-Model Connector: Document & Graph Relations for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5821

1. The Vision: Multi-Model Database Intelligence in Graph RAG

Modern applications frequently run on multi-model databases that seamlessly blend document storage, relational tables, and native graph relationships. SurrealDB represents the state-of-the-art in this paradigm. Traditional database connectors flatten multi-model records into generic SQL rows, discarding the essential graph edge relationships (such as RELATE user:alice->purchased->product:laptop).

The cognee-community-connector-surrealdb bridges this gap by extracting both document properties and native graph edge pointers (in and out relations), ensuring Cognee's entity extraction and Graph RAG memory capture interconnected organizational truth.

2. Architecture & REST Discovery

The connector interfaces directly with SurrealDB's HTTP /sql endpoint using the client's namespace (NS) and database (DB) headers with Bearer token or Basic authentication.

Architectural Highlights:
  • Pre-flight Schema Discovery: Executes INFO FOR DB; to automatically discover available tables and schemas when explicit table lists are not provided.
  • Graph Edge Preservation: Detects SurrealDB edge tables and maps in (origin node) and out (target node) relationships as first-class metadata.
  • Bounded Extraction: Enforces table-level limits to ensure large datasets do not saturate graph vector buffers.
  • Dual Authentication Support: Supports both JWT Bearer tokens and username/password Basic authentication for local and cloud SurrealDB deployments.

4. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_surrealdb import SurrealDBConnector
import cognee

async def main():
    # Initialize connector targeting local or cloud SurrealDB instance
    connector = SurrealDBConnector(
        namespace="production",
        database="analytics",
        url="http://localhost:8000",
        username="root",
        password="root",
        tables=["customer", "order", "purchased"],
        limit_per_table=50,
    )

    print("Extracting multi-model data and graph edges from SurrealDB...")
    documents = await connector.fetch_all()
    print(f"Retrieved {len(documents)} records from SurrealDB.")

    # Ingest into Cognee Knowledge Graph
    for doc in documents:
        await cognee.add(doc["clean_text"])

    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())
