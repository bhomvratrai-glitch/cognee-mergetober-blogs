Flarum Community Forum Connector: Conversational Memory for AI Agents

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #6216

1. The Problem: Indexing Developer Discussion Forums

Flarum powers thousands of open-source and developer community forums. Users discuss architectural questions, troubleshooting steps, and plugin recommendations. Without a native ingestion connector, AI agents could not index and reason across multi-reply discussion threads.

2. Architecture: Multi-Post Thread Serialization

Built under packages/connector/flarum/, the connector queries Flarum's standard JSON:API endpoints to synthesize full discussion threads into coherent Markdown documents:

Highlights:
• Chronological Reply Streams: Ingests all discussion posts, preserving author timestamps and conversation context.
• HTML Cleansing: Converts Rich Text and HTML post formatting into clean readable Markdown without breaking inline formatting.
• Flexible Access: Works for open public forums as guest without keys, and supports private admin API tokens.
• Hermetic Testing: 3/3 unit tests passed offline in 0.82s.

3. Quickstart Code

import asyncio
import os
import cognee
from cognee_community_connector_flarum import flarum_source

async def main():
    source = flarum_source(
        base_url=os.getenv("FLARUM_BASE_URL", "https://discuss.flarum.org"),
        tags=["general", "feedback"],
        limit=20,
    )
    await cognee.add(source)
    await cognee.cognify()

    results = await cognee.search("What common issues are reported regarding extension installations?")
    for res in results:
        print("-", res)

if __name__ == "__main__":
    asyncio.run(main())
