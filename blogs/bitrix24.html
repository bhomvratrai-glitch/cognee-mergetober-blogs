Bitrix24 CRM Connector: Enterprise Pipeline & Customer Intelligence for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #6297

1. The Problem: CRM Memory Silos in Enterprise AI

Bitrix24 powers over 12 million organizations worldwide with its integrated CRM, pipeline automation, company records, and client communications. However, when building AI sales copilots and automated support agents, this vital operational context remains trapped behind REST API endpoints. An LLM cannot reason over ongoing customer deals, negotiation stages, or timeline comments without direct access to structured knowledge graphs.

2. Technical Architecture & Inbound Webhook Design

The cognee-community-connector-bitrix24 connects securely via Bitrix24's native inbound webhook architecture. Unlike complex OAuth2 flows that require continuous token refresh servers, inbound webhooks provide dedicated REST authorization scoped directly to CRM resources.

Key Architectural Highlights:
  • Pipeline Deals & Opportunities: Pulls deal stages, opportunity values, currencies, associated companies, and contact IDs.
  • Timeline Comments Threading: Queries chronological discussion notes per record to capture negotiation context and client requests.
  • Contacts & Organizations: Ingests lead profiles, communication channels (phone/email), and corporate hierarchy.
  • Pacing & Leaky Bucket Resilience: Adheres to Bitrix24's 2 req/s limit with explicit handling for 401 invalid credentials, 429 operation time limits, and 503 query limit errors.

3. Code Walkthrough: Ingestion into Cognee

import asyncio
from cognee_community_connector_bitrix24 import Bitrix24Connector
import cognee

async def main():
    webhook_url = "https://your-company.bitrix24.com/rest/1/secret_token/"
    connector = Bitrix24Connector(webhook_url=webhook_url)

    # Ingest deals, contacts, and companies with timeline comments
    documents = await connector.to_documents(
        crm_types=["deal", "contact", "company"],
        limit_per_type=20,
        include_comments=True
    )

    # Cognify into vector and knowledge graph memory
    await cognee.add(documents)
    await cognee.cognify()

    await connector.close()

if __name__ == "__main__":
    asyncio.run(main())
