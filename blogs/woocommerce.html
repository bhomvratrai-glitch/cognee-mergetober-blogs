WooCommerce Store Connector: Autonomous E-Commerce Memory for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5776 / #5884

1. The Vision: Unifying Self-Hosted E-Commerce Intelligence

WooCommerce powers over 28% of the top 1 million online stores worldwide. Self-hosted merchants handle rich customer signals daily: product catalog descriptions, stock availability, verified user reviews, checkout customer delivery notes, and order fulfillment tracking notes. Enabling AI agents to reason directly over this data unlocks next-generation conversational shopping assistants and automated customer support copilots.

2. REST Integration Architecture

The cognee-community-connector-woocommerce integrates directly with WooCommerce REST API v3 using Consumer Key and Secret authentication.

Architectural Highlights:
  • Product Catalogs & Pricing: Ingests regular and sale prices, stock statuses, SKUs, category taxonomies, and HTML-sanitized descriptions.
  • Verified Customer Reviews: Links 5-star ratings and reviewer feedback directly to products in the cognitive knowledge graph.
  • Orders & Fulfillment Timeline: Pulls purchased item subtotals, fulfillment states, checkout customer notes, and internal staff timeline notes.
  • Customer Privacy Safeguard: Built-in PII shield (include_customer_pii=False) prevents personal customer addresses or phone numbers from vector memory ingestion.

3. Code Walkthrough: Ingestion into Cognee

import asyncio
from cognee_community_connector_woocommerce import WooCommerceConnector
import cognee

async def main():
    connector = WooCommerceConnector(
        store_url="https://your-store.com",
        consumer_key="ck_your_consumer_key",
        consumer_secret="cs_your_consumer_secret",
        include_customer_pii=False
    )

    # Ingest products with verified reviews and orders with timeline notes
    documents = await connector.to_documents(
        include_products=True,
        include_orders=True,
        limit_per_type=20
    )

    # Cognify into vector and knowledge graph memory
    await cognee.add(documents)
    await cognee.cognify()

    await connector.close()

if __name__ == "__main__":
    asyncio.run(main())
