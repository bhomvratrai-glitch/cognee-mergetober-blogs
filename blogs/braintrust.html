Braintrust AI Evaluation Platform Connector: LLMOps Memory for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #6303

1. The Problem: LLM Benchmarks & Prompt Registries Trapped in Silos

Braintrust is the industry standard platform for evaluating LLMs, tracking RAG accuracy experiments, and versioning prompts. When engineering teams build autonomous agents, connecting evaluation metrics directly into the agent's knowledge graph enables intelligent introspection over which prompt variations and models perform best.

2. Architecture: Multi-Entity LLMOps Graph Serialization

Implemented under packages/connector/braintrust/, our connector bridges Braintrust's REST API into Cognee memory:

Highlights:
• Projects & Evaluation Experiments: Extracts experiment scores (factuality, relevance, latency percentiles) and hyperparameter configurations into queryable Markdown.
• Evaluation Datasets: Ingests golden test suites and benchmark dataset metadata.
• Prompt Registry: Captures versioned system prompt templates and model architectures.
• Hermetic Testing: 4/4 passing offline unit tests covering projects, experiments, datasets, and prompts in 0.75s.

3. Quickstart Code

import asyncio
import os
import cognee
from cognee_community_connector_braintrust import braintrust_source

async def main():
    source = braintrust_source(
        api_key=os.getenv("BRAINTRUST_API_KEY"),
        project_names=["rag-eval-prod"],
        include_prompts=True,
        include_datasets=True,
    )
    await cognee.add(source)
    await cognee.cognify()

    results = await cognee.search("Which experiments achieved the highest factuality scores?")
    for res in results:
        print("-", res)

if __name__ == "__main__":
    asyncio.run(main())
