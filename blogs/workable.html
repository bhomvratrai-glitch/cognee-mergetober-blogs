Workable ATS Connector: Recruiting & Talent Pipeline Intelligence for Cognee

By Bhomvrat Rai (@bhomvratrai-glitch) • Issue #5878

1. The Vision: Bringing Hiring & Talent Ops into Knowledge Graphs

Workable is a leading recruiting platform and Applicant Tracking System (ATS) used by over 27,000 businesses globally to post open roles, source talent, manage candidate pipelines, and coordinate hiring teams. For autonomous enterprise AI agents, knowledge of ongoing hiring requisitions, team growth priorities, and candidate talent pipelines provides real-time organizational context that informs resource planning, project velocity estimates, and cross-functional capacity.

2. Architecture & Pipeline Ingestion

The cognee-community-connector-workable package connects directly to the Workable REST API using account subdomains and API Bearer tokens.

Key Architectural Capabilities:
  • Job Requisition Ingestion: Ingests role title, department, employment type, location (country, city, remote status), requirements, and application URLs.
  • Candidate Pipeline Stage Tracking: Normalizes candidate status across hiring stages (applied, screened, interviewed, offered, hired, disqualified) with timestamps.
  • Clean Text Sanitization: Automatically strips rich HTML job descriptions and candidate notes into clean semantic text ready for LLM vectorization.
  • Configurable Privacy Guards: Supports excluding sensitive personal candidate details while retaining talent pipeline stage velocity metrics.

3. Quickstart & Cognee Ingestion

import asyncio
from cognee_community_connector_workable import WorkableConnector
import cognee

async def main():
    connector = WorkableConnector(
        api_key="your_workable_api_key",
        subdomain="your_company_subdomain",
        state="published",
        fetch_candidates=True,
    )

    print("Fetching jobs and talent pipelines from Workable...")
    data = await connector.fetch_all()
    print(f"Retrieved {len(data['jobs'])} jobs and {len(data['candidates'])} candidates.")

    # Ingest into Cognee Knowledge Graph
    for job in data["jobs"]:
        await cognee.add(job["clean_text"])
    
    await cognee.cognify()
    print("Ingestion & Cognify complete!")

if __name__ == "__main__":
    asyncio.run(main())

4. Verification & Testing

The connector features a 100% hermetic unit test suite verifying job listing extraction, candidate stage mapping, authentication error handling, and text sanitization without requiring active external network connections.
